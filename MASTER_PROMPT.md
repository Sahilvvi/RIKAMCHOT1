# 54. MOTION DESIGN SYSTEM

Create a complete motion system organized by intention and depth.

DESIGN PHILOSOPHY

"Do not use animation to make the website look impressive. Use animation to make the product easier to discover, understand, configure and purchase."

Motion is not decoration. Motion explains, reveals or guides.

THE 5 MOTION LEVELS

Level 1 — Micro Motion

Everyday interactions. Fast and subtle: 150–300ms.

* Button hover
* Add-to-cart
* Wishlist
* Dropdown
* Filter
* Image swap
* Quantity changes

Level 2 — Interface Motion

Navigation and structural transitions. Smooth and directional: 300–600ms.

* Mega menu
* Search
* Cart drawer
* Product quick view
* Modal
* Page transition

Level 3 — Product Motion

This is where the product becomes interactive.

* 360°
* 3D rotation
* Product configuration
* Material changes
* Colour changes
* Product assembly
* Exploded view

Level 4 — Storytelling Motion

Premium content only.

* Scroll-controlled animation
* Pinned sections
* Parallax
* Product transformations
* Text masking
* Image reveals
* Cinematic transitions
